# 正项级数怎样通过比较判断收敛？ {#u-06-23-03}

## 先备知识

非负项使部分和单调不减；单调数列收敛，当且仅当它有上界。比较两个有限部分和时，
必须记录不等式从哪个指标开始最终成立。有限项不改变敛散性，却会改变和与余项常数。

## 学习目标

完成本单元后，你应能：

1. 把正项级数收敛转化为部分和有上界；
2. 正确使用直接比较的收敛与发散方向；
3. 证明正有限极限下的极限比较判别；
4. 解释 \(L=0\) 与 \(L=\infty\) 只给单向结论；
5. 从逐项比较保留余项上界。

## 牵引问题

若一个未知正项级数的每一项都不超过某个已知收敛级数，对有限部分和逐项相加就能得到
统一上界。反过来，若未知级数更大而基准级数发散，又会发生什么？比较方向能否交换？

## 探索与猜想

对最终满足 \(0\le a_n\le b_n\) 的两列，尾段也满足

\[
0\le\sum_{k=m+1}^{n}a_k\le\sum_{k=m+1}^{n}b_k.
\]

因此“小于收敛者”继承尾部控制；“大于发散者”不可能拥有有界部分和。其余两个方向
没有保证。

## 概念与理论

### 正项级数的单调部分和 {#thm-u-06-23-03-positive-monotone}

**定理。** 若 \(a_n\ge0\)，则 \(\sum a_n\) 收敛，当且仅当其部分和数列有上界。

**证明。** \(S_{n+1}-S_n=a_{n+1}\ge0\)，所以 \((S_n)\) 单调不减。由单调收敛定理，
它收敛当且仅当有上界。证毕。

### 直接比较判别 {#thm-u-06-23-03-direct-comparison}

设从某个 \(N_0\) 起最终成立

\[
0\le a_n\le b_n.
\]

则有两条合法方向：

1. 若上方级数收敛，即 \(\sum b_n\) 收敛，则 \(\sum a_n\) 收敛；
2. 若下方级数发散，即 \(\sum a_n\) 发散，则 \(\sum b_n\) 发散。

**证明。** 第一条中，\(a_n\) 的尾部部分和被 \(b_n\) 的有限总尾和控制，因而有上界；
第二条是第一条的逆否命题，也可直接比较部分和。有限的前 \(N_0-1\) 项不影响敛散性。
证毕。

“大于收敛级数”和“小于发散级数”都没有结论。例如调和级数大于收敛的
\(\sum1/n^2\)，却发散；\(\sum1/n^2\) 小于发散的调和级数，却收敛。

### 极限比较判别 {#thm-u-06-23-03-limit-comparison}

设 \(a_n,b_n>0\)，且

\[
\lim_{n\to\infty}\frac{a_n}{b_n}=L,\qquad 0<L<\infty.
\]

则 \(\sum a_n\) 与 \(\sum b_n\) 同敛散。

**证明。** 取 \(\varepsilon=L/2\)。充分大的 \(n\) 满足

\[
\frac L2<\frac{a_n}{b_n}<\frac{3L}{2},
\]

即

\[
\frac L2 b_n<a_n<\frac{3L}{2}b_n.
\]

两次使用直接比较即得同敛散。证毕。

若 \(L=0\)，只能说 \(a_n\) 最终比 \(b_n\) 小：当 \(\sum b_n\) 收敛时可推出
\(\sum a_n\) 收敛。若 \(L=\infty\)，当 \(\sum b_n\) 发散时可推出
\(\sum a_n\) 发散。没有相应基准结论时，不能强行分类。

### 比较同时给出余项控制 {#cor-u-06-23-03-tail-bound}

若从 \(N_0\) 起 \(0\le a_n\le Cb_n\)，且 \(\sum b_n\) 收敛，则对 \(m\ge N_0\)，

\[
0\le R_m^{(a)}
=\sum_{n=m+1}^{\infty}a_n
\le C\sum_{n=m+1}^{\infty}b_n
=C R_m^{(b)}.
\]

因此比较不仅判定收敛；只要保留常数 \(C\)、生效指标和基准尾界，就得到余项上界。

## 例题与迁移

### 例 1：有理式的极限比较 {#ex-u-06-23-03-rational}

对

\[
a_n=\frac{3n+1}{n^3+4},
\]

取 \(b_n=1/n^2\)。有

\[
\frac{a_n}{b_n}=\frac{3n^3+n^2}{n^3+4}\to3.
\]

因 \(\sum1/n^2\) 收敛，原级数收敛。

### 例 2：比较方向诊断 {#ex-u-06-23-03-direction}

\[
\frac1{n^2+n}\le\frac1{n^2}
\]

且右侧收敛，所以左侧收敛。若只写
\(\frac1{n^2+n}\le1/n\)，右侧发散，不能得出任何结论。

### 例 3：比较保留尾界 {#ex-u-06-23-03-tail}

若 \(n\ge2\)，

\[
0\le\frac1{n^2-1}\le\frac2{n^2}.
\]

一旦第 23.5 建立 \(p=2\) 的积分尾界，就可得

\[
\sum_{n=m+1}^{\infty}\frac1{n^2-1}
\le2\sum_{n=m+1}^{\infty}\frac1{n^2}
\le\frac2m.
\]

## 即时检验与回望

### 即时检验 1

已知 \(0\le a_n\le1/n\)。能否判断 \(\sum a_n\)？

??? note "答案"

    不能。小于发散级数无结论；例如可取 \(a_n=1/n\) 或 \(a_n=1/n^2\)。

### 即时检验 2

若 \(a_n/b_n\to0\) 且 \(\sum b_n\) 收敛，怎样严格推出 \(\sum a_n\) 收敛？

??? note "答案"

    取阈值 \(1\)。充分大时 \(0\le a_n\le b_n\)，使用直接比较。

## 习题与答案

### 习题 1 {#pr-u-06-23-03-01}

判定 \(\sum 1/(n^2+5)\)。

??? note "答案"

    \(0\le1/(n^2+5)\le1/n^2\)，由上方级数收敛得原级数收敛。

### 习题 2 {#pr-u-06-23-03-02}

判定 \(\sum (2n+3)/(n^2+1)\)。

??? note "答案"

    与 \(1/n\) 极限比较，比值趋于 \(2\)，所以发散。

### 习题 3 {#pr-u-06-23-03-03}

指出“\(1/n^2\le1/n\)，所以 \(\sum1/n^2\) 发散”的错误。

??? note "答案"

    下方较小级数不能从上方发散继承发散性；比较方向反了。

### 习题 4 {#pr-u-06-23-03-04}

判定 \(\sum (n+1)/(n^3+n)\)。

??? note "答案"

    与 \(1/n^2\) 极限比较，比值
    \(n(n+1)/(n^2+1)\to1\)，故收敛。

### 习题 5 {#pr-u-06-23-03-05}

设 \(a_n/b_n\to L\in(0,\infty)\)。写出证明中可替代 \(L/2\) 的一般选择。

??? note "答案"

    任取 \(0<\varepsilon<L\)，最终有
    \((L-\varepsilon)b_n<a_n<(L+\varepsilon)b_n\)。

### 习题 6 {#pr-u-06-23-03-06}

给出 \(a_n/b_n\to0\) 但两级数都发散的例子。

??? note "答案"

    取 \(a_n=1/n\)、\(b_n=1/\sqrt n\)。比值为 \(1/\sqrt n\to0\)，两者均发散。

### 习题 7 {#pr-u-06-23-03-07}

给出 \(a_n/b_n\to\infty\) 但两级数都收敛的例子。

??? note "答案"

    取 \(a_n=1/n^2\)、\(b_n=1/n^3\)。比值为 \(n\to\infty\)，两者均收敛。

### 习题 8 {#pr-u-06-23-03-08}

若 \(0\le a_n\le3/n^2\) 对 \(n\ge10\) 成立，写出 \(m\ge10\) 时的比较余项界。

??? note "答案"

    \(R_m^{(a)}\le3\sum_{n=m+1}^{\infty}1/n^2\)。结合积分尾界可进一步得
    \(R_m^{(a)}\le3/m\)。

## 常见误区与后续

1. 用“小于发散者”或“大于收敛者”强行下结论。
2. 忘记比较只需最终成立，却又忽略其生效指标。
3. 在极限比较中把 \(L=0\) 或 \(L=\infty\) 当成正有限极限。
4. 得到敛散结论后丢掉比较常数，错失余项上界。

获得最终几何控制。
