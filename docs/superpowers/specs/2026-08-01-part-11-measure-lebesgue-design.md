# 第十一部：测度与 Lebesgue 积分设计

**日期：** 2026-08-01

**范围：** 第 46–50 章，25 个核心单元，38 学时（理论 31，应用 7）

**核心问题：** Riemann 积分失效后，“大小”与“总量”应怎样重建？

## 1. 目标与定位

第十一部从一个递增的 Riemann 可积函数列出发，系统建立 Lebesgue 外测度、
Carathéodory 可测性、可测函数、Lebesgue 积分以及三大收敛定理。组织方式采用
“对象逐层升级型”：

\[
\text{Riemann 失败序列}
\longrightarrow
\text{集合的大小}
\longrightarrow
\text{可测集合}
\longrightarrow
\text{可测函数}
\longrightarrow
\text{Lebesgue 积分}
\longrightarrow
\text{收敛定理}.
\]

本部完整证明关键存在性与交换结论，不把 Python、有限覆盖搜索或图像观察升级为
测度、可测性、几乎处处收敛或积分交换的证明。核心安排为 38 学时，38 学时是硬上限。
完成后全书出版口径为 234 个核心单元、405 学时。

## 2. 序章动机与教学闭环

在 \([0,1]\) 中枚举有理数 \(q_1,q_2,\ldots\)，定义

\[
f_n=\mathbf 1_{\{q_1,\ldots,q_n\}}.
\]

每个 \(f_n\) 只有有限个不连续点，Riemann 可积且积分为零；函数列递增逐点收敛到
\(\mathbf 1_{\mathbb Q\cap[0,1]}\)，而极限函数处处不连续，不再 Riemann 可积。
序章只由此提出四个问题，不提前使用本部结论：

1. 可数集的长度为什么应当为零？
2. 可数并为什么要求集合类对可数运算封闭、大小函数可数可加？
3. 函数列的逐点极限怎样保持可测性？
4. 非负递增极限为什么应允许积分与极限交换？

第 46–50 章依次回收这些问题。第 50 章再回到同一函数列，用已经证明的测度、可测性、
积分与单调收敛定理闭合全篇。序章不另设编号章节、核心单元或额外学时。

## 3. 组织方案

采用“对象逐层升级型”，没有采用以下两种备选方案：

1. **抽象测度优先型：** 先建立一般测度空间，再把 Lebesgue 测度作为例子。接口整齐，
   但会弱化从长度问题出发的动机。
2. **收敛问题驱动型：** 从多个 Riemann 失败序列倒推全部概念。问题感强，但定义与证明
   会反复回溯，依赖不再单向。

测度构造采用外测度—Carathéodory 路线。从区间长度构造 Lebesgue 外测度，再定义
Carathéodory 可测集并证明其构成 σ-代数，最后限制外测度得到 Lebesgue 测度。不把
Carathéodory 判据或“区间外测度等于长度”作为黑箱，也不展开一般测度扩张定理。

## 6. 数学与证明合同

1. 外测度定义中的覆盖必须是可数开区间族，下确界必须对全部允许覆盖取得。
2. 外测度单调性与可数次可加性的量词、重编号和 \(\varepsilon\) 分配必须完整。
3. 区间外测度的下界必须证明，不能只证明存在长度相等的覆盖。
4. Carathéodory 判据必须对任意测试集成立；只检查区间或有限样本不足。
5. σ-代数封闭性和测度可数可加性必须从已证性质推出，不引用一般扩张定理。
6. 可测函数的水平集刻画、运算封闭和逐点极限封闭必须注明扩展实值边界。
7. 简单函数逼近必须给出显式递增构造，并同时证明逐点收敛与可测性。
8. 简单函数积分必须与表示无关；非负积分的可加性先由递增简单函数引理证明，不得循环
   调用第 50 章的一般单调收敛定理；一般积分必须避开 \(\infty-\infty\)。
9. MCT、Fatou 和 DCT 必须写出完整假设、证明链和至少一个条件失败反例。
10. Riemann–Lebesgue 比较只使用本部已建立的一维工具，不前借第十二部或范围外理论。
11. 序章函数列在五章中逐步回收，不能在序章提前宣告尚未证明的 Lebesgue 结论。
12. 计算或绘图输出只描述有限输入，不承担数学对象存在性或无限过程证书职责。

## 7. 应用与计算模块

新增 `mathbook_examples.lebesgue_approximation`，提供两个公开接口：

```python
simple_integral(values, measures)

finite_cover_upper_bound(intervals)
```

`simple_integral` 只计算已经声明为互不相交可测分块上的有限简单函数积分。它验证：

- `values` 与 `measures` 是等长、非空的有限实数序列；
- 测度非负且有限；
- 每个乘积及最终求和均为有限实数；
- 布尔值不作为实数输入接受。

接口不检查集合是否真的可测或互不相交；调用页面必须明确这是输入合同，而不是算法
验证结果。

`finite_cover_upper_bound` 接受有限个端点有限且右端点不小于左端点的区间，合并重叠后
返回覆盖并的总长度。结果对象至少包含：

- `upper_bound`：合并后区间总长度；
- `merged_intervals`：实际使用的互不重叠区间；
- `input_count` 与 `merged_count`；
- `status="finite_cover_only"`。

该结果只能作为被覆盖集合外测度的候选上界。有限区间族、有限搜索或较小的新结果都不
证明已经达到外测度下确界。绘图与采样统一标记为 `observed`。
