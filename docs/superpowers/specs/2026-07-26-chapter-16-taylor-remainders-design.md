# 第 16 章“Taylor 公式与余项”设计

## 1. 目标与定位

第 16 章把前四章建立的导数、中值定理与高阶导数组织成有限阶局部近似。核心问题是：

> 已知展开点附近的有限阶导数，怎样构造一个多项式，并准确说明它在哪种意义下接近原
> 函数？

章节采用“余项阶梯式”结构：

\[
\text{Peano 的局部渐近}
\longrightarrow
\text{Lagrange 的可计算上界}
\longrightarrow
\text{Cauchy 的中值结构}
\longrightarrow
\text{可信数值近似}.
\]

三种余项都完整陈述和证明，但不压缩成一个抽象的一般余项定理。每种证明突出不同的可
迁移方法：

- Peano：归纳与 Lagrange 中值定理；
- Lagrange：带多重零点的辅助函数与反复 Rolle；
- Cauchy：逐项抵消的辅助函数与 Cauchy 中值定理。

理论是章节骨架，\(e^x\)、\(\sin x\)、\(\log(1+x)\) 的近似故事和数值微分实验负责
说明何时需要哪一种余项。

## 4. 统一记号

对展开中心 \(a\)，定义 \(n\) 阶 Taylor 多项式

\[
P_n(x)
=
\sum_{k=0}^{n}
\frac{f^{(k)}(a)}{k!}(x-a)^k.
\]

余项统一记为

\[
R_n(x)=f(x)-P_n(x).
\]

定理从任意中心 \(a\) 陈述。例题优先从 \(a=0\) 的 Maclaurin 情形开始，再迁移到
非零中心。所有公式保持同一阶数约定：

- 多项式最高次数为 \(n\)；
- Lagrange、Cauchy 余项使用 \(f^{(n+1)}\)；
- Lagrange 余项分母为 \((n+1)!\)；
- Cauchy 余项分母为 \(n!\)。

## 5. 单元设计

### 5.1 单元 16.1：Peano 余项与局部渐近结构

#### 条件合同

“\(f\) 在 \(a\) 具有直到 \(n\) 阶的可导结构”在正文中展开说明：

- \(n=1\) 时，\(f\) 在 \(a\) 可导；
- \(n\ge2\) 时，\(f'\) 在 \(a\) 的某个邻域存在，并在 \(a\) 具有直到
  \(n-1\) 阶的可导结构。

等价地，可逐阶定义 \(f^{(k)}(a)\) 到 \(k=n\)，并有足够的邻域导数使归纳中的
Lagrange 中值定理合法。这个条件不要求 \(f^{(n)}\) 在 \(a\) 连续，甚至不要求
\(f^{(n)}\) 在整个去心邻域存在。

#### 定理与证明

Peano 公式为

\[
f(x)
=
P_n(x)
+o\!\left((x-a)^n\right),
\qquad x\to a.
\]

证明固定采用归纳法：

1. \(n=1\) 是一点可导的局部线性化定义；
2. 设结论对 \(n-1\) 成立，令 \(G=f-P_n\)；
3. 对 \(G'\) 使用归纳假设，得到
   \[
   G'(t)=o\!\left((t-a)^{n-1}\right);
   \]
4. 对 \(G\) 在 \(a\) 与 \(x\) 之间使用 Lagrange 中值定理：
   \[
   G(x)=G'(\xi)(x-a);
   \]
5. 由 \(|\xi-a|\le|x-a|\) 推出
   \[
   G(x)=o\!\left((x-a)^n\right).
   \]

证明必须显式处理 \(x<a\) 时的绝对值，不用“同理”掩盖符号或区间方向。

#### 系数唯一性

在上述逐阶可导条件下，若

\[
f(a+h)
=c_0+c_1h+\cdots+c_nh^n+o(h^n),
\]

则逐阶证明

\[
c_k=\frac{f^{(k)}(a)}{k!}.
\]

先由 Peano 定理得到以导数为系数的标准展开，再比较两个展开式，取最低次非零系数并
除以相应幂次，得到矛盾。正文必须说明，唯一性依赖于余项确实是 \(o(h^n)\)，而不是
模糊的“高阶小量”；系数与导数的对应还使用了开头的逐阶可导条件。

#### 例题与边界

主线例题至少包括：

- \(e^x\) 与 \(\sin x\) 在零点的有限阶 Peano 展开；
- 用 Peano 展开求一个不需要误差上界的局部极限；
- 一个因所需高阶导数不存在而不能继续展开的边界例。

本单元不声称 Peano 余项提供给定 \(x\ne a\) 的数值上界。

### 5.2 单元 16.2：Lagrange 余项与误差预算

#### 条件合同

对固定 \(x\ne a\)，要求 \(f\) 在包含 \(a\) 与 \(x\) 之间闭线段的某个开区间内
具有直到 \(n+1\) 阶导数。这样低阶导函数自动连续，反复 Rolle 的每一步均合法；不
额外要求 \(f^{(n+1)}\) 连续。

#### 定理与证明

令

\[
R=f(x)-P_n(x)
\]

并构造

\[
F(t)
=
f(t)-P_n(t)
-R\left(\frac{t-a}{x-a}\right)^{n+1}.
\]

核验

\[
F(a)=F(x)=0,
\qquad
F^{(k)}(a)=0
\quad(1\le k\le n).
\]

反复使用 Rolle 定理，得到某个严格位于 \(a,x\) 之间的 \(\xi\)，使

\[
F^{(n+1)}(\xi)=0.
\]

因此

\[
R_n(x)
=
\frac{f^{(n+1)}(\xi)}{(n+1)!}(x-a)^{n+1}.
\]

正文逐层解释每一次 Rolle 使用的两个零点从哪里来，而不是只写“反复应用即得”。

#### 可计算误差界

若在 \(a,x\) 之间

\[
|f^{(n+1)}(t)|\le M,
\]

则

\[
|R_n(x)|
\le
\frac{M}{(n+1)!}|x-a|^{n+1}.
\]

本单元用该不等式完成两种任务：

1. 已知阶数，计算误差上界；
2. 已知误差预算，寻找满足要求的最低阶数。

例题优先使用高阶导数容易统一控制的 \(e^x\)、\(\sin x\) 与 \(\cos x\)。每次必须
写出 \(M\) 控制的具体区间，不能只列公式。

### 5.3 单元 16.3：Cauchy 余项与三种余项比较

#### 定理与证明

使用与 Lagrange 余项相同的区间高阶可导条件。固定 \(x\)，构造

\[
\Phi(t)
=
f(x)
-
\sum_{k=0}^{n}
\frac{f^{(k)}(t)}{k!}(x-t)^k.
\]

求导时要求正文展示前几项的消去规律，再写一般结论：

\[
\Phi'(t)
=
-\frac{f^{(n+1)}(t)}{n!}(x-t)^n.
\]

又有

\[
\Phi(a)=R_n(x),
\qquad
\Phi(x)=0.
\]

对 \(\Phi(t)\) 与 \(x-t\) 使用 Cauchy 中值定理，得到严格位于 \(a,x\) 之间的
\(\xi\)，使

\[
R_n(x)
=
\frac{f^{(n+1)}(\xi)}{n!}(x-\xi)^n(x-a).
\]

证明必须核对 Cauchy 中值定理的分母函数导数为 \(-1\)，因此不存在除零漏洞。

#### 三种余项比较

本单元设置正式比较表：

| 余项 | 条件强度 | 结论形态 | 主要用途 |
|---|---|---|---|
| Peano | 展开点逐阶可导 | \(o((x-a)^n)\) | 局部渐近、等价比较 |
| Lagrange | 连接区间上 \(n+1\) 阶可导 | 单点高阶导数乘 \((x-a)^{n+1}\) | 直接误差上界 |
| Cauchy | 连接区间上 \(n+1\) 阶可导 | \((x-\xi)^n(x-a)\) | 揭示中值结构、替代估计 |

正文明确：

- 三种余项不是三个可以无条件互换的记号；
- Peano 条件较弱，但通常不给定点误差证书；
- Lagrange 与 Cauchy 的中间点一般未知，也不要求相同；
- Cauchy 形式不是把 Lagrange 公式简单代数变形得到。

### 5.4 单元 16.4：误差预算、Horner 与数值微分

本单元采用“轻量误差主线”：

\[
\text{给定误差预算}
\longrightarrow
\text{选择阶数}
\longrightarrow
\text{形成 Taylor 系数}
\longrightarrow
\text{Horner 求值}
\longrightarrow
\text{解释实际误差}.
\]

随后把 Taylor 公式用于前向和中心差分，说明步长过大时截断误差占主导，步长过小时
浮点相消和舍入误差会被放大。

#### 数值微分的理论边界

在相应邻域内二阶导数存在并有界时，

\[
\frac{f(x+h)-f(x)}h
=
f'(x)+O(h).
\]

在相应邻域内三阶导数存在并有界时，

\[
\frac{f(x+h)-f(x-h)}{2h}
=
f'(x)+O(h^2).
\]

两条误差阶结论必须与高阶可微和有界条件同时出现。正文不把观测到的数值收敛倒过来
当成函数可导或高阶光滑的证明。

## 6. 算法设计

新增唯一算法模块：

```text
src/mathbook_examples/differentiation.py
```

### 6.1 Taylor 多项式求值

公开接口：

```python
evaluate_taylor(coefficients, center, point)
```

`coefficients[k]` 表示

\[
\frac{f^{(k)}(a)}{k!},
\]

即 \((x-a)^k\) 的系数。函数计算

\[
c_0+c_1z+\cdots+c_nz^n,
\qquad z=\text{point}-\text{center},
\]

并使用逆序 Horner 递推：

\[
v\leftarrow c_n,\qquad
v\leftarrow vz+c_k.
\]

拒绝：

- 空系数序列；
- 非有限系数；
- 非有限中心或求值点；
- 产生非有限中间值或结果的计算。

返回一个有限浮点数，不附带余项证书。余项上界必须由调用者依据具体函数、区间和导数
界另行证明。

### 6.2 差分接口

公开接口：

```python
forward_difference(function, point, *, step=None)
centered_difference(function, point, *, step=None)
```

两者返回不可变结果对象 `DifferenceEstimate`：

```text
value   实际导数近似
step    实际使用的正步长
method  "forward" 或 "centered"
```

结果对象不包含 `error_bound` 或 `certified` 字段，模块文档与函数文档必须明确：
自动步长是经验选择，不提供误差证书。

显式步长必须为正且有限。`step=None` 时，设

\[
\varepsilon=\texttt{sys.float\_info.epsilon},
\qquad
s=\max(1,|x|),
\]

并使用：

\[
h_{\mathrm{forward}}=\sqrt{\varepsilon}\,s,
\qquad
h_{\mathrm{centered}}=\sqrt[3]{\varepsilon}\,s.
\]

这些规则来自截断误差与舍入误差的量级平衡，只作为教材级经验策略，不称为对任意函数
最优。

拒绝：

- 非有限求值点；
- 非有限、零或负的显式步长；
- 非有限采样点；
- 函数在任一采样点返回非有限值。

函数抛出的其他异常不吞掉、不改写，以便保留原始定义域错误。

### 6.3 教材实验

第 16.4 页至少包含：

1. 用 Lagrange 上界为一个 \(e^x\) 或 \(\sin x\) 近似选择最低阶数；
2. 形成升幂 Taylor 系数并用 `evaluate_taylor` 求值；
3. 比较真实误差与理论上界，强调上界通常不等于实际误差；
4. 对光滑函数制作步长递减表，比较前向与中心差分；
5. 展示误差先减小、后因相消与舍入而增大的现象；
6. 比较自动经验步长与至少两个显式步长。

不新增自动扫阶、自动估计高阶导数界或自动认证误差的接口。
