# 第十一部一致性终审

日期：2026-08-01

## 对象升级与依赖闭合

- 序章从有限有理点指示函数列出发，依次驱动外测度、可测集、可测函数、Lebesgue 积分和收敛定理。
- 第 46–50 章共 25 个核心单元，理论 31 学时、应用 7 学时，总计 38 学时；单元 ID、导航与物理页面一一对应。
- 第五部仅交付一维 Riemann/Darboux 基线；第六部仅交付逐点/一致收敛对照；第八部仅交付 Jordan 边界；第十部仅交付经典交换条件。
- 第 49 章的积分可加性由递增简单函数引理闭环，不循环调用第 50 章 MCT；Fatou 和 DCT 严格沿已发布依赖推出。

## 计算与证书边界

- `simple_integral` 与 `finite_cover_upper_bound` 各只有一个 Python 定义源。
- 前者只计算已证明可测且互不相交的有限分块；后者只返回 `finite_cover_only` 上界，不声称求得外测度。
- 数值输出不替代可测性、可积性、极限交换或误差证明。

## 范围与出版闭合

- 已发布 5 份章级一致性审查；每章 50 道稳定锚点习题、60 个折叠答案。
- 全书发布口径为第 50 章、234 个学习单元、405 学时。
- 本部不含一般测度延拓定理、乘积测度、Tonelli、Fubini、Radon–Nikodym 或 `L^p` 空间；未创建第 51 章。
