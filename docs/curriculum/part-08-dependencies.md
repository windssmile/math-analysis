## 前后接口

- **已有输入：** 第五部 Riemann 积分与一元求积；第七部 Euclid 空间、紧致性、
  一致连续性、Fréchet 微分、Jacobian 与反函数定理。
- **理论主线：** 闭矩形上的 Riemann 重积分 → 累次积分 → 变量代换 →
  反常重积分。
- **应用副线：** 区域描述与换序 → 二维张量积中点法 → 质量、质心、转动惯量与
  连续型联合密度模型。
- **后续输出：** 为第九部提供区域与坐标变换，为第十部提供累次与反常积分经验，
  为第十一部提供 Riemann/Jordan 理论的具体边界。

## 唯一主责边界

1. 正文采用经典 Riemann 重积分，不以 Jordan 或 Lebesgue 理论为前置。
2. 累次积分只在连续函数和正文允许的常用区域内建立，不讲测度论版
   Fubini–Tonelli。
3. 变量代换在一一对应、连续可微、Jacobian 不退化及有限边界分片条件下处理。
4. 概率只讲连续型联合密度、边缘密度、期望与协方差，不讲条件分布。
5. 数值核心只有矩形域二维张量积中点法，不讲一般 cubature 或随机误差理论。
6. 曲线积分、曲面积分与 Green/Gauss/Stokes 留给第九部。
7. 数值结果只核验计算，不证明可积性、换元条件或反常收敛。
