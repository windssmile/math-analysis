## 经典证明顺序与取向检查

1. 弧长、线积分、面积元和曲面积分先定义，再推导计算公式；物理模型不承担定义。
2. Green、Gauss、Stokes 分别先在简单区域、长方体、单个参数曲面片上证明，再以
   有限分片和内部边界抵消推广；三大公式的统一不替代各自证明。
3. 每次重新参数化都区分保向与反向；每个方向敏感问题都必须写明参数方向、法向量、
   边界方向和右手规则。
4. 多连通区域逐支检查外边界与内边界方向；闭曲面使用外法向；挖孔区域同时检查新增
   内边界及其极限。
5. 使用公式前必须检查连续可微性、分片光滑性、正则性、诱导边界方向和奇点排除。

## 范围排除与证书边界

- 不发展一般流形、切丛、链、同调、上同调或完整外代数理论。
- 不发展弱向量分析、弱导数或分布意义的散度与旋度。
- 不引入测度论线积分或曲面积分。
- 不用有限数值实验证明参数化不变性、正则性或 Green、Gauss、Stokes 定理。
- 数值计算只能核验方向、法向量、Jacobian 因子和解析结果，不自动形成数学证书。
