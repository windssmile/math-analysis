## 序章问题与证明主线

枚举 \([0,1]\) 内有理数为 \(q_1,q_2,\ldots\)，令
\(f_n=\mathbf 1_{\{q_1,\ldots,q_n\}}\)。每个函数 Riemann 可积且积分为零，逐点极限
却是处处不连续的有理数指示函数。第十一部由此追问可数集大小、可数运算、极限函数
可测性以及积分与单调极限的交换。

证明主线固定为：区间长度 → Lebesgue 外测度 → Carathéodory 可测集与测度 →
可测函数与简单函数 → Lebesgue 积分 → 单调收敛、Fatou 引理、控制收敛 →
Riemann 理论比较。后一步只能调用前一步已经发布的结果。
